## 🎨 Points Forts Graphiques & Ergonomiques

1. **Photographies Professionnelles Haute Définition** :
   - Fini les prospectus ou flyers intégrés en image brute.
   - Intégration de photographies nettes d'environnements propres : bureaux modernes, baies vitrées lumineuses, sols polis, chantiers rénovés.
2. **Logo Officiel Nettoyé & Transparent** :
   - Logo officiel avec intégration nette sans bordure blanche.
3. **Simulateur de Devis Interactif & WhatsApp Direct** :
   - Calculateur en direct selon la surface en m² et la fréquence avec remise automatique (-15% hebdo, -10% bimensuel).
   - Envoi immédiat en 1 clic sur WhatsApp (+32 492 96 99 96) avec message pré-rempli.
4. **Comparateur Interactif Avant / Après** :
   - Curseur coulissant pour visualiser l'efficacité du passage de nos équipes.
5. **SEO & Données Structurées Belgique** :
   - Balisage Schema.org LocalBusiness, balises meta pour le référencement naturel à Liège, Ans, Bruxelles et en Wallonie.

## 🚀 Test en Local & Déploiement

### 1. Visualiser en local
Le serveur local est actif. Vous pouvez visiter :
👉 **`http://localhost:8080`**

### 2. Déploiement chez votre hébergeur (One.com)
Ce site est entièrement statique (HTML, CSS, JavaScript natif, images optimisées) :
- Téléversez tous les fichiers à la racine de votre hébergement FTP chez One.com (`index.html`, toutes les pages `.html`, le dossier `css/`, `js/` et `assets/`).
- Aucune base de données complexe ni plugin lourd nécessaire : temps de chargement ultra-rapide (< 1 seconde).
